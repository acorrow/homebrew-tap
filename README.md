# acorrow/homebrew-tap

Homebrew tap for CLI utilities by Adam Corrow.

## Install `zsplash` (`zsp`)

```zsh
brew install acorrow/tap/zsplash
```

This installs both `zsplash` and the `zsp` shorthand alias.

### Install or update straight from the `develop` branch (`--HEAD`)

```zsh
brew install --HEAD acorrow/tap/zsplash
# Later, to pull the latest commits from develop:
brew upgrade --fetch-HEAD zsplash
```
